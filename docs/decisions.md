- S06 (2026-08-19): Normalization is a pure deterministic function (`normalize_series()`), separate from persistence (`persist_normalized()`). Units are canonical from the catalog and values are NEVER converted at this layer - any unit transformation is a labelled derived metric (S08). Frequency inferred from median month-gap (tolerates one missing period; irregular spacing is an error, not a guess). Seasonal adjustment is caller-overridable per series because FRED/WB differ (SA vs NSA CPI); the applied value is stored per observation. Fixed in-unit: WB/ILOSTAT connectors were stamping `vintage=period`, contradicting the documented snapshot semantics - both now stamp `vintage=retrieval date`, so observation identity changes on each refetch and revisions stay visible (RQ4). `release_time=retrieval_time` remains a documented proxy until S07.
- S07 (2026-08-29): Quality grades form a closed vocabulary imported from the S03 API contract (single source of truth); priority is flagged > ungraded > revised > official, and `preliminary`/`estimated` are RESERVED - never emitted because no source exposes release-stage metadata (emitting them would be fabrication). Flags are INSERT-only (audit trail); grades are UPDATE (judgement). Revision semantics: a revision is a new (period, vintage) row, never an update; `relative` deltas are None on zero bases or value<->missing transitions. ALFRED realtime queries are live-only (no silent mocks for vintage data), which required rekeying the S06 duplicate check from period to (period, vintage) so vintage chains can normalize and persist. `release_calendar` stays unpopulated - no API exposes scheduled-release timestamps; a future populated calendar must be sourced, not fabricated.
- S08 (2026-08-29): Transformations are pure functions over `SeriesPoint` -> `DerivedPoint` with explicit missingness on BOTH sides (closed reason vocabulary: insufficient_history, input_missing, zero_base, non_positive_base, incomplete_window). Percent change against zero/negative bases is MISSING, not infinity or a misleading ratio (documented policy). Rolling means require complete consecutive windows - never silently re-denominated. Formula definitions live in the `FORMULAS` registry recorded verbatim into `metric_versions.definition`; `formula_ref` must resolve to a registry name (no free-text drift). Derived persistence: only computable values become rows (schema forbids NULL); missing outputs stay in the returned list with reasons - the engine never fabricates a row. Engine reads the LATEST vintage per period (S07 superseded semantics) as transform input. Metric key convention: `{indicator_id}.{formula_name}`.
- S09 (2026-08-29): Standardization is robust (median/MAD) over a trailing FIXED-SIZE window - outliers cannot dominate the scale and the definition never depends on future data; no normal-consistency constant is applied (comparability, not normality). Partial window occupancy is recorded per output, never hidden; MAD==0 is missing (`zero_scale`), never fabricated. `direction` is a catalog presentation convention (policy_rate NEUTRAL - adjustment would assert a judgment); positive consistently reads favorable vs the country's own median, raw deviation retained. Panel coverage is ratio of sums (mean-of-ratios would weight 2-period and 40-period series equally). Publication gates check CONDITIONS (coverage/counts/evidence/chronology), not S07 grade labels - one source of truth, and every failure carries an explicit reason code; default thresholds documented (0.5 coverage, 3 observations - the minimum where a median is an observed value). Standardized scores persist as `{indicator}.robust_z{window}` with the `robust_z` FORMULAS registry entry.
- S10 (2026-08-29): RQ lenses are a separate layer (`src/macropulse/lenses/`) from metrics/quality - they consume machinery and impose research-question semantics. The labor lens is component-first: no index, no composite score, no weights (weighting is a judgment the platform does not make; a composite would hide the divergence RQ1 asks about). Gap AND ratio are both reported (they describe different labor markets; neither collapses into the other). Enrollment is reported but never combined - combining it would embed a causal "education reduces unemployment" judgment the non-claims boundary forbids. One period + one vintage per profile (vintage analysis compares separate profiles); period alignment across differently-lagged sources is the caller's explicit job (live finding: ILOSTAT NEET lags WB unemployment by a year). Unfetched components carry `component_not_fetched`; the lens returns no relationship rather than fabricating.
