- S06 (2026-08-19): Normalization is a pure deterministic function (`normalize_series()`), separate from persistence (`persist_normalized()`). Units are canonical from the catalog and values are NEVER converted at this layer - any unit transformation is a labelled derived metric (S08). Frequency inferred from median month-gap (tolerates one missing period; irregular spacing is an error, not a guess). Seasonal adjustment is caller-overridable per series because FRED/WB differ (SA vs NSA CPI); the applied value is stored per observation. Fixed in-unit: WB/ILOSTAT connectors were stamping `vintage=period`, contradicting the documented snapshot semantics - both now stamp `vintage=retrieval date`, so observation identity changes on each refetch and revisions stay visible (RQ4). `release_time=retrieval_time` remains a documented proxy until S07.
- S07 (2026-08-29): Quality grades form a closed vocabulary imported from the S03 API contract (single source of truth); priority is flagged > ungraded > revised > official, and `preliminary`/`estimated` are RESERVED - never emitted because no source exposes release-stage metadata (emitting them would be fabrication). Flags are INSERT-only (audit trail); grades are UPDATE (judgement). Revision semantics: a revision is a new (period, vintage) row, never an update; `relative` deltas are None on zero bases or value<->missing transitions. ALFRED realtime queries are live-only (no silent mocks for vintage data), which required rekeying the S06 duplicate check from period to (period, vintage) so vintage chains can normalize and persist. `release_calendar` stays unpopulated - no API exposes scheduled-release timestamps; a future populated calendar must be sourced, not fabricated.
- S08 (2026-08-29): Transformations are pure functions over `SeriesPoint` -> `DerivedPoint` with explicit missingness on BOTH sides (closed reason vocabulary: insufficient_history, input_missing, zero_base, non_positive_base, incomplete_window). Percent change against zero/negative bases is MISSING, not infinity or a misleading ratio (documented policy). Rolling means require complete consecutive windows - never silently re-denominated. Formula definitions live in the `FORMULAS` registry recorded verbatim into `metric_versions.definition`; `formula_ref` must resolve to a registry name (no free-text drift). Derived persistence: only computable values become rows (schema forbids NULL); missing outputs stay in the returned list with reasons - the engine never fabricates a row. Engine reads the LATEST vintage per period (S07 superseded semantics) as transform input. Metric key convention: `{indicator_id}.{formula_name}`.
- S09 (2026-08-29): Standardization is robust (median/MAD) over a trailing FIXED-SIZE window - outliers cannot dominate the scale and the definition never depends on future data; no normal-consistency constant is applied (comparability, not normality). Partial window occupancy is recorded per output, never hidden; MAD==0 is missing (`zero_scale`), never fabricated. `direction` is a catalog presentation convention (policy_rate NEUTRAL - adjustment would assert a judgment); positive consistently reads favorable vs the country's own median, raw deviation retained. Panel coverage is ratio of sums (mean-of-ratios would weight 2-period and 40-period series equally). Publication gates check CONDITIONS (coverage/counts/evidence/chronology), not S07 grade labels - one source of truth, and every failure carries an explicit reason code; default thresholds documented (0.5 coverage, 3 observations - the minimum where a median is an observed value). Standardized scores persist as `{indicator}.robust_z{window}` with the `robust_z` FORMULAS registry entry.
- S10 (2026-08-29): RQ lenses are a separate layer (`src/macropulse/lenses/`) from metrics/quality - they consume machinery and impose research-question semantics. The labor lens is component-first: no index, no composite score, no weights (weighting is a judgment the platform does not make; a composite would hide the divergence RQ1 asks about). Gap AND ratio are both reported (they describe different labor markets; neither collapses into the other). Enrollment is reported but never combined - combining it would embed a causal "education reduces unemployment" judgment the non-claims boundary forbids. One period + one vintage per profile (vintage analysis compares separate profiles); period alignment across differently-lagged sources is the caller's explicit job (live finding: ILOSTAT NEET lags WB unemployment by a year). Unfetched components carry `component_not_fetched`; the lens returns no relationship rather than fabricating.
- S11 (2026-08-29): RQ2's lens separates REACH (levels) from INCLUSION (gaps) structurally - a single blended measure would hide exactly the divergence the question asks about, same logic as S10's no-index rule. The gender gap is a conservative proxy (female minus all-adult average, understating the female-male deficit) because the male series is not in the locked catalog - repurposing the catalog's female Findex fallback source as a source-level auxiliary keeps the catalog locked while naming the limitation. `rank_covariation` is Spearman with (rho, n) always returned: a 10-economy panel cannot support Pearson normality assumptions, and a coefficient without n hides fragility. `measurement_gap` takes `as_of` from the caller (lens purity, no clock reads). Live findings recorded rather than smoothed over: the WB API returns NULL placeholder rows for unpublished years (alignment must use OBSERVED periods - returned periods would fabricate all-NULL profiles), Findex waves are 2024 not 2025 (catalog corrected against the live source), and JPN's profile aligns to 2021 because its stalest dimension (mobile, 2023) binds - the lens makes the constraint visible instead of mixing vintages to hide it.
- S12 (2026-08-29): RQ3 splits along its evidence types - the payment PROFILE is statistical (lens layer) while the EPISODES are documents, so episodes carry the `external` label (never `real`) and citation is a CONSTRUCTOR rule: an uncited episode cannot be instantiated, moving no-fabrication from review discipline into the type system. No arithmetic relationship between payment prevalence and health spending (recorded policy, tested by asserting the profile has zero properties) - combining them would embed a dependence claim. The blind-spot answer is computed where it is arithmetic and stated where it is a fact about the indicator list: observation_alignment proves the recurring year-end 48h suspension straddles every catalog frequency boundary (unresolvable at every frequency), while the construct gap (no indicator measures operational continuity) is documented, not faked as a check. Episode windows are timezone-aware China Standard Time - the sources state local time, and a naive window is ambiguous; scheduled vs unplanned is enforced by announcement timing (scheduled must be announced before its window; unplanned may be published after). Verified-record governance: measure comparability pinned per record (Beijing authorized vs national total beds), record year carried next to exposure figures, and 29/31 provinces named unrecorded rather than imputed.
- S13 (2026-09-01): The query service implements the S03-pinned schemas VERBATIM (verified byte-identical; a stray `ruff format` rewrap of the pinned file was reverted - the pin outranks format conformity, and the test suite asserts the served observation key set equals `ObservationOut.model_fields` so drift fails a test). Closed vocabularies (module, evidence_label, quality_grade) are `Literal` query params: invalid values are 422s listing the legal values, never silent empty pages that read as "no data" - unknown open-ended IDs (indicator, country) remain filter semantics. `latest_vintage` composes with filters (max-vintage subquery built from the same filtered query), not applied after them. Pagination is uniform: limit/offset with `X-Total-Count` of the unpaginated filtered set and deterministic ordering, so an empty page is visibly a page. Health reports backing, not content (`data_mode="database"`/`"database-unreachable"`; content claims live on per-row evidence labels). Methodology is served from where it actually lives: formulas from the `FORMULAS` registry, per-metric definitions from recorded `metric_versions` rows, and an unknown metric key is 404 - "no methodology" must not be indistinguishable from "never heard of it". A derived row with no recorded version is skipped rather than served with an invented version string. Dependencies use the `Annotated` style (`DbSession`), which is both the FastAPI-recommended pattern and B008-clean without noqa.
- S14 (2026-09-01): The dashboard consumes the QUERY SERVICE over HTTP (architecture data flow: service -> dashboard), never the DB directly, so it cannot bypass the S03-pinned provenance contract. All view logic is pure functions in `macropulse.views.assembly` (tested as data, 26 tests); Streamlit rendering stays a thin untested glue layer verified live via Streamlit's AppTest harness. Missing data is a NAMED state everywhere: tables render `missing (<reason>)` (or `missing (no reason recorded)` - itself an out-of-contract signal), chart traces keep `None` with `connectgaps=False` so gaps render instead of interpolated lines (an interpolated line through a missing period would fabricate data). No shared chart axis across different units (a shared axis would mislead; multi-unit selections get the table only). Values display at full precision - the dashboard shows exactly what the service served. The client refuses silent truncation: pagination follows X-Total-Count and a stream longer than announced raises. st.stop() never fires inside tabs (it halts the whole run, blanking sibling tabs); tab-local empty states are if/else branches. Coverage displays counts, not judgments - S09's gate thresholds are not re-applied here. quality_grade renders as a plain provenance column (hiding a served provenance field would violate "preserve source metadata"); badges/freshness/limits refinement is S15's unit. Cache keys are API URL strings, not client objects (hashability).
- S15 (2026-09-03): Freshness is ARITHMETIC ON OBSERVATION DATES, not a release-schedule claim: state (current/lagging/no_data) = age from the last OBSERVED period to a caller-supplied as-of date, in frequency steps, with a documented 2-step lag threshold (same standing as S09's direction rule and S12's resolvable rule - a presentation convention in code and tests, not reviewer memory). No expected-release framing is invented because the release calendar is unpopulated by S07 decision. The as-of date is a sidebar control (the dashboard's only clock read, UTC default) - labels derive from the value, never a hidden clock; negative ages are shown, not clamped (hiding them would be silent sanitization). Quality badges DECORATE the closed S07 grade vocabulary, never replace it - the grade word travels with the symbol, and an unknown grade renders `unknown(<grade>)` (visible, never remapped). Chart captions count only from the observations rendered (the missing-points clause appears only when there are missing points). Limitations/comparability render from the S02 CODE-LEVEL catalog, not a new API field - `IndicatorOut` is S03-pinned and stays unchanged; this extends the S13 pattern (static methodology from code, dynamic data from the API), with an explicit "no catalog entry" line for served-but-uncatalogued indicators. The legend is a governance surface: `cached` is honestly marked "not yet emitted" (grep-verified that no emitter exists). Hover provenance travels per point on chart traces so tooltips match tables.
- S16 (2026-09-03): The Architecture section-5 AI boundary is enforced as MACHINERY, not prompt discipline: prose derives only from a validated JSON contract (`BriefingFacts` - the S01 non-claim "AI-generated prose derives only from validated structured inputs" made checkable), every statement is an atomic claim adjudicated against that JSON with a closed 8-reason rejection vocabulary, and any text must pass a banned-phrase check (causal/advice/forecast/merit - closed patterns). Non-real evidence is PARTITIONED OUT at facts construction, so a mocked value has no code path into a statement; change claims are built only across exactly one frequency step (a comparison across a gap would mislead about timing). Rejected claims are PERSISTED with validated=False - the audit trail records what was refused, not only what passed. No LLM is called (no key exists): the deterministic template generator is the no-key default (the S04 connector pattern), and `briefing_runs.model` records `deterministic-template` honestly; an LLM attached later is just another prose source behind the same validators. The document is pure (no clock reads - the run row records time, the document does not). The disclaimer-was-banned-phrases incident is the unit's lesson: the Limitations footer initially said "no forecasts ... no investment advice", which trips the mechanical check on our own document; the check gets NO exemption for good intentions, so the wording changed - a disclaimer using banned literals is indistinguishable, to the check, from prose committing them.
- S17 (2026-09-10): The refresh layer persists REVISION DIFFS, not snapshots: a normalized row is born only when a period is first observed or its (value, missing_reason) changed vs the latest stored vintage; unchanged re-observations are archived in the RAW store only - raw is the complete retrieval archive, normalized is the revision chain (this makes re-runs idempotent, live-proved: an immediate re-run wrote 0 new rows over 10 series x 66 periods, and keeps RQ4 chains readable since every row is a change, not a daily no-op). The scheduler is STDLIB (no APScheduler - large-wheel installs have failed on this network; platform cron alone leaves nothing testable in-repo), with injected clock/sleep; 06:00 UTC is a polling CONVENTION, explicitly not a release-schedule claim (release calendar unpopulated by S07 decision). FRED without a key fails with reason `no_api_key` BEFORE any DB write - the scheduled layer never falls back to the S04 mocked fixture (that would be "mocked presented as observed"); `cached` stays reserved/unemitted (grep re-verified) because the layer stores real rows or records failure, never re-labels. Plan = PRIMARY sources only x structured per-source country coverage (`SourceRef.countries`, None = whole panel) - fallback application stays a human decision, and the structured field structurally prevents fetching a US-only FRED code (FEDFUNDS) as another economy. Per-series isolation: raw archive commits FIRST (the fetch did happen - provenance survives even a normalization rejection), then normalized rows; one failing series never aborts others and progress commits per series. Run records are append-only audit (`refresh_runs`, migration c9af6b543047): stale `running` rows are marked `interrupted` by the next run; closed vocabularies everywhere (triggers manual/scheduled/recovery; statuses running/succeeded/partial/failed/interrupted; failure reasons no_api_key/fetch_failed/normalization_error/persist_error/unknown). Retry boundary: only HTTP 429/5xx and transport errors retry (max 3 attempts, 1s then 2s - bounded ~3s added latency per failing series, injectable sleep); 4xx and parse errors fail on attempt 1. Exit codes 0/1/2 = succeeded/partial/failed so cron can alert without parsing. The dev DB was untouched by the live demo (disposable `macropulse_s17_demo`, created/migrated/dropped by the demo script) because the briefing run rows on the dev DB are append-only audit records.
- S18 (2026-09-24): The visual language is a TOKEN LAYER (`views/theme.py`), never inline styling: an entity-fixed 10-hue palette over exactly the S01 panel where an unknown country RAISES rather than defaulting (a silent hue would fabricate identity), color follows the entity and never its rank (the USA→CHN focus switch repaints nothing - proved in the render leg), and at most ONE colored line renders at a time (focus-and-context). The palette is VALIDATOR-RUN (not reasoned): lightness/chroma/normal-vision-floor PASS, protan 7.7 and sub-3:1 contrast are floor-band WARNs legal only under the relief rule (every chart ships secondary encoding - direct label + legend + table view). FT-referenced, not cloned (user directive): serif headline/hairline grid/recessive non-data ink/whitespace/direct labels adopted; the newsroom palette and dark mode are not. Light mode is PINNED via `.streamlit/config.toml` so an automatic dark flip cannot silently invalidate the validated palette - one mode rendered right. Documented macro-episodes are DATA (`case_study/macro_episodes.py`), inheriting the S12 rule: citation-mandatory constructor, always `external`, live-verified URL; the registry holds exactly the 2020 WHO pandemic window - no episodes were invented to fill it. The annotation layer is PURE overlay builders with the causal-wording filter run IN PRODUCTION (a wording regression raises at render time, not in review); the band is a wash drawn BELOW the lines, clipped to the rendered range, with the narrow-band rule (a window under 1% of the rendered range gets the wash but no callout - a label must not claim more window than the source documents) and the direct label sits on the focus line's last OBSERVED point only (a gap is never labeled - that would fabricate a position). End-to-end proof is the six-leg harness on a disposable DB: byte-check (served vs stored, value by exact repr, 6/6 fields) rather than spot values, derived lineage verified DB-side because the S13 pinned schema has no inputs field (0 diff re-verified), and the render asserted on the served figure JSON. AppTest lessons recorded for future units: `set_value` takes RAW widget values (format_func labels crash serialization), charts are found via `at.get("plotly_chart")` with the full figure in `el.proto.spec`, and every `at.run()` is followed by an `at.error` guard because `st.stop()` paths raise no AppTest exception and read as "0 charts" otherwise.
