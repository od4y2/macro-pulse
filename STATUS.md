# STATUS

S16 accepted on 2026-09-03. The structured AI briefing layer (`src/macropulse/briefing/`) generates prose ONLY from validated JSON with citations, under rejection tests - the Architecture section-5 AI boundary implemented as machinery rather than prompt discipline. FACTS (`facts.py`): `BriefingFacts.from_observations` consumes ObservationOut-shaped dicts from the S13 query service and partitions them - real-evidence values are facts (the only statements a briefing may make), real NULLs are missing (surfaced as availability statements), and non-real evidence (mocked/synthetic/cached/external) is excluded and counted in Limitations, so a mocked value is structurally never a fact; construction rejects duplicate vintages for one period and out-of-vocabulary evidence labels. CLAIMS (`claims.py`): every statement is an atomic claim (level / change / availability) carrying its cited observations' S03 identity; built by deterministic templates (one level claim per country+indicator at the latest observed period; change claims only when the two latest observed periods are exactly one frequency step apart - no "rose from" across gaps; one availability claim per missing observation); ADJUDICATION validates every claim against the same JSON with a closed 8-reason rejection vocabulary (fact_not_found, value_mismatch, evidence_not_real, missing_value_claimed, citation_missing, citation_mismatch, availability_contradicted, reason_mismatch), each reason exercised by a test. PROSE (`prose.py`): the document assembles from validated claims only (rejected text never renders; rejection counts appear under Limitations), and `check_prose` is the banned-phrase rejection layer (causal/advice/forecast/merit - closed named patterns) that the rendered document must itself pass; the Limitations footer was deliberately reworded to avoid the banned literals because a disclaimer using them would be indistinguishable to the mechanical check from prose committing them. Values render at full precision; the document is pure (no clock reads, no I/O). PERSISTENCE (`run.py`): one briefing_runs row (model `deterministic-template`, prompt_version `s16-v1` - no LLM is called, no key exists, and the audit row says so honestly; an LLM attached later is another prose source behind the same validators) plus one briefing_claims row per attempt INCLUDING rejected claims with validated=False - the audit trail records what was refused, not only what passed. No LLM call was made or claimed. 35 new tests (451/451). Live demo: 110 real observations fetched from the running service over the typed S14 client -> 20 claims (10 level + 10 change) all validated -> document passes check_prose with zero findings -> tampered-value claim rejected (value_mismatch) and causal sentence rejected (causal_phrase) as deliberate demonstrations -> run 1 persisted to the dev DB and re-read (21 rows, evidence_refs JSON round-tripped).
