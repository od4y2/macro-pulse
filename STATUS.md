# STATUS

S17 accepted on 2026-09-10. The operational layer (`src/macropulse/ops/`) adds scheduled updates, logs, retry boundaries, and safe failure behavior. RETRY (`retry.py`): only HTTP 429/500/502/503/504 (`RetryableFetchError`, now raised by all three connectors via `http_error()`) and `httpx.TransportError` are retryable - 4xx and parse errors fail on attempt 1; RetryPolicy(3 attempts, 1s then 2s, injectable sleep) bounds worst-case added latency at ~3s per failing series; exhaustion re-raises the last error. RUNS (`runs.py`): closed vocabularies throughout - triggers `manual|scheduled|recovery`, run statuses `running|succeeded|partial|failed|interrupted`, series statuses `ok|failed`, failure reasons `no_api_key|fetch_failed|normalization_error|persist_error|unknown`; a stale `running` row means the process died and the next run marks it `interrupted` (the audit trail never says running forever). LOGGING (`logging_setup.py`): JSONL events (ts/level/event + fields, default=str) to stderr plus an appending file (`logs/refresh.jsonl` default, gitignored); the same events drive the run row, so log and DB cannot diverge. REFRESH (`refresh.py`): the planner crosses catalog PRIMARY sources with structured `SourceRef.countries` coverage (new catalog field; None = whole panel) - 111 series by default, and FEDFUNDS is structurally USA-only so a US series can never be fetched as another economy; per-series isolation commits the RAW archive first (the fetch did happen), then normalized rows, so one failing series never aborts others; REVISION-DIFF persistence - a normalized row is born only when a period is first observed or its (value, missing_reason) changed vs the latest stored vintage, unchanged re-observations are raw-archive-only (idempotent re-runs, readable RQ4 revision chains, bounded growth); FRED without `FRED_API_KEY` fails `no_api_key` BEFORE any write (no mocked fixture data in the governed store); CLI: one-shot (cron-able), `--daemon` (stdlib daily 06:00 UTC loop - a POLLING convention, not a release-schedule claim), `--dry-run`; exit codes 0/1/2 = succeeded/partial/failed. SCHEDULER (`scheduler.py`): stdlib, injected clock/sleep, slot strictly after now. 12th table `refresh_runs` (migration `c9af6b543047`): one append-only audit row per cycle with per-series outcomes JSON. `cached` evidence label stays reserved/unemitted (grep re-verified) - the layer stores real rows or records failure. 46 new tests (497/497).
